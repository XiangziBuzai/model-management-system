# 模型管理系统 - 实现规划

## Context

用户需要为"模型清单.xlsx"文件数据构建一个完整的 Web 管理系统，将 Excel 中的模型/工具数据持久化到 MySQL，并提供增删改查、筛选、Excel批量导入和数据统计等功能。  
技术栈：Vue 3 + Element Plus + Vite（前端）/ Spring Boot 3.x + MyBatis Plus + EasyExcel（后端）/ MySQL 8.x。  
开发模式：本地前后端分离，前端端口 5173，后端端口 8080，Excel 以上传文件方式导入。

## 一、数据库设计

数据库名：`model_management`（`utf8mb4`）

### 建表 SQL

```sql
CREATE DATABASE IF NOT EXISTS model_management
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE model_management;

-- 厂家表
CREATE TABLE manufacturer (
  id          BIGINT       NOT NULL AUTO_INCREMENT COMMENT '主键',
  name        VARCHAR(100) NOT NULL                COMMENT '厂家名称',
  description VARCHAR(500)                         COMMENT '描述',
  created_at  DATETIME     DEFAULT NOW()           COMMENT '创建时间',
  updated_at  DATETIME     DEFAULT NOW() ON UPDATE NOW() COMMENT '更新时间',
  deleted     TINYINT(1)   DEFAULT 0               COMMENT '逻辑删除(0正常/1删除)',
  PRIMARY KEY (id),
  UNIQUE KEY uk_name (name)
) COMMENT='厂家表';

-- 模型表
CREATE TABLE model (
  id               BIGINT         NOT NULL AUTO_INCREMENT COMMENT '主键',
  manufacturer_id  BIGINT         NOT NULL               COMMENT '厂家ID',
  name             VARCHAR(200)   NOT NULL               COMMENT '模型名称',
  price            DECIMAL(10,2)  NOT NULL               COMMENT '价格',
  remark           VARCHAR(500)                          COMMENT '备注',
  created_at       DATETIME       DEFAULT NOW(),
  updated_at       DATETIME       DEFAULT NOW() ON UPDATE NOW(),
  deleted          TINYINT(1)     DEFAULT 0,
  PRIMARY KEY (id),
  UNIQUE KEY uk_manufacturer_name (manufacturer_id, name),
  KEY idx_price (price)
) COMMENT='模型表';

-- 工具表
CREATE TABLE tool (
  id          BIGINT        NOT NULL AUTO_INCREMENT COMMENT '主键',
  name        VARCHAR(200)  NOT NULL                COMMENT '工具名称',
  price       DECIMAL(10,2) NOT NULL                COMMENT '价格',
  remark      VARCHAR(500),
  created_at  DATETIME      DEFAULT NOW(),
  updated_at  DATETIME      DEFAULT NOW() ON UPDATE NOW(),
  deleted     TINYINT(1)    DEFAULT 0,
  PRIMARY KEY (id),
  UNIQUE KEY uk_name (name)
) COMMENT='工具表';
```

## 四、REST API 接口

| GET | `/api/models/{id}` | 查单条 |
| POST | `/api/models` | 新增 |
| PUT | `/api/models/{id}` | 编辑 |
| DELETE | `/api/models/{id}` | 逻辑删除 |
| DELETE | `/api/models/batch` | 批量删除（body: ids数组） |

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/manufacturers` | 全量列表（下拉框） |
| POST | `/api/manufacturers` | 新增 |
| PUT | `/api/manufacturers/{id}` | 编辑 |

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/tools?page=1&size=20&name=&minPrice=&maxPrice=` | 分页+筛选 |
| POST | `/api/tools` | 新增 |
| PUT | `/api/tools/{id}` | 编辑 |

## 五、关键实现要点

### 后端

1. **CORS 配置**（`CorsConfig.java`）  
   实现 `WebMvcConfigurer.addCorsMappings`，`allowedOriginPatterns("http://localhost:5173")`，允许所有方法和头部，`allowCredentials(true)`

2. **MyBatis Plus 逻辑删除**  
   `application.yml` 配置 `logic-delete-field: deleted`，所有查询自动追加 `WHERE deleted=0`

3. **分页查询**（`ModelMapper.xml`）  
   动态 SQL：`LEFT JOIN manufacturer`，`<if test="manufacturerName!=null">` 等条件拼接，配合 `Page<ModelVO>` 返回

4. **Excel 导入流程**（`ExcelImportServiceImpl`）
   - EasyExcel 逐行解析，每 500 行一批
   - 批量 `upsert` 厂家（按名称 UNIQUE KEY）
   - 构建 Model 列表，`saveOrUpdateBatch`（按 `manufacturer_id+name` 去重）
   - `@Transactional`，单批次失败不影响其他批次
   - 返回成功数/失败数/错误行详情

5. **application.yml 关键配置**
   ```yaml
   server:
     port: 8080
   spring:
     datasource:
       url: jdbc:mysql://localhost:3306/model_management?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
     servlet.multipart:
       max-file-size: 10MB
   mybatis-plus:
     global-config.db-config:
       logic-delete-field: deleted
   ```

### 前端

1. **Vite 代理**（`vite.config.js`）  
   `/api` → `http://localhost:8080`，解决开发期跨域

2. **Axios 拦截器**（`request.js`）  
   响应拦截器解构 `Result<T>`，非 200 自动 `ElMessage.error`

3. **ECharts 图表**（Dashboard.vue）  
   厂家占比饼图 + 价格区间柱状图，数据从 `/api/statistics` 并行获取

4. **Excel 上传组件**（ExcelImport.vue）  
   `el-upload` 手动上传模式，`FormData` 包装文件调用 `/api/import/excel`，展示导入结果表格

## 七、验证方式

- **后端**：启动后访问 `http://localhost:8080/swagger-ui.html`，用 Swagger UI 测试各接口
- **数据库**：执行 `SELECT * FROM model LIMIT 5` 验证数据结构
- **Excel 导入**：上传原始模型清单.xlsx，检查导入成功数与 Excel 行数匹配
- **前端**：访问 `http://localhost:5173`，逐一验证列表分页、新增、编辑、删除、筛选、统计图表功能
- **联调**：在前端新增一条模型记录，刷新列表确认持久化
